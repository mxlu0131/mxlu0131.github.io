# Mengxi Lu

Personal academic homepage and NHANES survival risk calculator.

- Homepage: https://mxlu0131.github.io/
- Calculator: https://mxlu0131.github.io/calculator.html

Static HTML, CSS and JavaScript. Inference runs locally in the browser; inputs are not transmitted or stored. This demonstration uses an existing Cox model and aggregate NHANES analysis results. No individual participant records, full report or downloadable CSV are included.

Layout inspired by [Academic Pages](https://github.com/academicpages/academicpages.github.io); independently implemented.
